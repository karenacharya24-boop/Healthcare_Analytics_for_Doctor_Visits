# Healthcare Analytics for Doctor Visits

## 📌 Project Overview

This project analyses doctor-visit patterns using Python and healthcare data. It explores how demographic characteristics, income, illness, health status, insurance coverage, reduced activity, and chronic conditions are associated with healthcare utilization.

## 🎯 Project Objectives

- Analyse doctor-visit patterns among individuals.
- Examine the relationships between age, gender, income, illness, and doctor visits.
- Investigate the association between insurance coverage and healthcare utilization.
- Explore reduced activity and chronic conditions.
- Identify patterns and relationships using statistical analysis and data visualization.

## ❓ Problem Statement

- Analyse doctor-visit patterns and healthcare utilization among individuals.
- Examine how demographic and socioeconomic factors relate to doctor visits.
- Investigate the association between insurance coverage, reduced activity, chronic conditions, and healthcare utilization.
- Identify meaningful patterns using statistical analysis and visualization techniques.

## 🛠️ Technologies Used

- **Python** — Programming language
- **Pandas** — Data manipulation and analysis
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization
- **Jupyter Notebook / Google Colab** — Development environment

## 📊 Project Workflow

1. Import the required Python libraries.
2. Load and inspect the dataset.
3. Perform data cleaning and check for missing or duplicate values.
4. Conduct exploratory data analysis (EDA).
5. Analyse doctor visits in relation to demographic, health, and insurance variables.
6. Create visualizations to identify patterns and relationships.
7. Summarize the findings and draw conclusions.

## 📈 Analysis and Visualizations

The project includes:

- Descriptive statistics and data inspection
- Missing-value analysis
- Gender and age distributions
- Doctor visits by gender and illness
- Relationships between visits, income, and health status
- Insurance-category analysis
- Reduced activity and chronic-condition analysis
- Correlation heatmap

## 🔍 Key Outcomes

The project provides an overview of doctor-visit patterns and explores how demographic, socioeconomic, and health-related variables are associated with healthcare utilization.

The findings are based on the available dataset and do not establish causal relationships.
